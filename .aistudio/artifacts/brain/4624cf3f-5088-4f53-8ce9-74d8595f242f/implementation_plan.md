# Duolingo利用規約・商標ガイドライン完全準拠 改善計画書

DuoStatsがDuolingoの利用規約（自動アクセス・スクレイピング禁止規約、商標・ブランド利用規約、ユーザープライバシー保護規程）に100%適法に準拠しているかを再監査し、規約リスクを確実に排除するための強化計画です。

## ユーザー確認・重要決定事項

> [!IMPORTANT]
> ユーザー様からの回答に基づき、**「オンデマンド照合＋手動安全記録のハイブリッド強化」**および**「非公式免責表記の徹底によるDuoStatsブランド継続」**の方針で規約対策を実施します。

- **確認済み決定 1（データ取得方針）**: 不正な定期自動巡回（クローラー）は一切行わず、ユーザーの明示的検索時のみ動作する「オンデマンド公開データ照合」と「手動セーフログ」のハイブリッドを強化。キャッシュ期間（15分）とリクエスト制限（Rate Limiting）を徹底。
- **確認済み決定 2（商標・ブランドガイドライン）**: サービス名「DuoStats」を維持しつつ、ヘッダー・フッター・検索画面・About全域で「非公式ファンサイト（Duolingo, Inc.とは無関係）」である旨の免責表記を視覚的に強化。
- **プライバシー保護＆オプトアウト**: ユーザーが自身のユーザー名や統計の蓄積をいつでも即座に完全抹消できるオプトアウト機能を維持・強化。

## 1. 規約監査結果と改善の核心コンセプト

### A. 自動アクセス・スクレイピング禁止規約への対策
- **規約条項**: Duolingo Terms of Service prohibits "use any robot, spider, crawler, scraper, or other automated means... to extract data".
- **監査と対策**:
  - ❌ **違反となる行為**: バックグラウンドでDuolingoサーバーを自動巡回してランキングを収集・蓄積するボット。
  - ✅ **準拠する設計**: 巡回ボットは一切配備せず、ユーザー自身が検索ボタンを押した瞬間のみ1回限り公開プロフィールを照合。
  - ✅ **アクセス保護の強化**: 1ユーザーあたり15分間のキャッシュを強制し、短時間の連続リクエストを防止。Duolingo側が429（Rate Limit）を返した際は即座にリクエストを中断し、手動入力モードへ案内。

### B. 商標およびブランド保護ガイドラインへの対策
- **規約条項**: Duolingo Trademark & Brand Guidelines prohibit creating confusion of official affiliation or unauthorized commercial use of trademarks.
- **監査と対策**:
  - ✅ **非公式性の明記**: 「DuoStatsはDuolingo, Inc.とは提携・後援関係のない非公式ファンプロジェクトです」「DuolingoはDuolingo, Inc.の商標です」の法的不認可条項（Disclaimer）をヘッダー直下、フッター、検索フォーム、About画面に明確に配置。
  - ✅ **独自デザインの保持**: 公式オウルマスコット等の商標グラフィックは使わず、汎用オープンソースアイコン（Lucide）およびNordic Modern UIで独自の世界観を統一。

## 3. 技術アーキテクチャ & 実装計画

### システム構成図
```
┌─────────────────┐       On-Demand Only (Cache 15m)       ┌──────────────────────┐
│  React Client   │ ─────────────────────────────────────> │  Node.js API Proxy   │
│  (Nordic UI)    │ <───────────────────────────────────── │  (server.ts)         │
└─────────────────┘       No passwords / cookies stored    └──────────┬───────────┘
         │                                                            │
         │ LocalStorage Only                                          ▼
         ▼                                                 ┌──────────────────────┐
┌─────────────────┐                                        │ Duolingo Public URL  │
│ Search History  │                                        │ (HTTPS single query) │
│ & Dark Theme    │                                        └──────────────────────┘
└─────────────────┘
```

### 具体的な変更ステップ
1. **`server.ts` & `duolingoService.ts`（アクセス保護・規約準拠強化）**:
   - キャッシュ有効期限を10分から15分に引き上げ、Duolingoサーバーへのリクエスト頻度をさらに抑制。
   - レートリミットヘッダーおよび短時間連打（同一IPからのスパム検索）のインターバル制限（クールダウン）を実装。
   - 429/403検出時の安全なレスポンス構築。
2. **`src/components/Navbar.tsx` & `src/components/Footer.tsx`**:
   - 非公式ファンサイト表記（Disclaimer）の文言を法的に盤石な水準にブラッシュアップ。
3. **`src/components/UserSearchForm.tsx`**:
   - 検索フォーム直下に「公開プロフィールのみ安全照合（パスワード不要）」の安心ガイドラインを追加。
4. **`src/components/AboutView.tsx`**:
   - Duolingo利用規約（第3条・第8条）に対する技術的対策を詳細化した「規約遵守ステートメント」を更新。
5. **テスト & ビルド検証**:
   - `compile_applet` および `npx tsx --test` で既存機能が全て正常に稼働することを確認。
